## Passo a passo: fornecedor realizando pedido no aplicativo

1. Acesse o aplicativo com o login de fornecedor.

2. Na tela inicial, toque na ação de novo pedido ou leitura de cliente.

3. Faça a leitura do código do associado/comprador ou selecione o cliente disponível para iniciar o pedido.

4. Na tela **Selecione uma loja**, escolha a loja/filial para a qual o pedido será feito.

5. O aplicativo abrirá a tela de negociações. Navegue pelas abas de negociação para visualizar os produtos disponíveis.

6. Para adicionar um produto ao pedido, toque no item desejado e informe a quantidade no campo exibido.

7. Repita o processo para todos os produtos necessários. O valor total do pedido será atualizado conforme as quantidades forem preenchidas.

8. Use a busca, a ordenação ou os filtros disponíveis para encontrar produtos com mais facilidade, quando necessário.

9. Toque em **Resumo do pedido** para conferir o total, os volumes, as lojas selecionadas e os itens por negociação.

10. Se precisar registrar alguma informação adicional, use a seção **Observação** e toque em **Adicionar** ou **Editar**.

11. Se o comprador tiver mais de uma loja vinculada e o pedido precisar ser replicado, abra **Duplicar para outras lojas** e marque as filiais desejadas.

12. Revise as negociações no resumo. Se precisar corrigir algum produto, toque na negociação correspondente para voltar à aba e ajuste a quantidade.

13. Com o pedido conferido, toque em **Finalizar Pedido**.

14. Aguarde a tela de sucesso confirmar que o pedido foi salvo.
